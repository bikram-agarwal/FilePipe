FilePipe is a powerful file management tool that turns your chaotic Download and other messy folders into a perfectly organized library — automatically. 🚀

Ever wanted all your videos in one folder, regardless of which app downloaded them? Or wished your Downloads folder would just sort itself into Documents, Music, Images, and everything else?

That's exactly what <b>FilePipe</b> does. Set a rule, pick a schedule, and let the pipes do the work. Move or copy any media to its rightful place.

<b>━━ 📋 RULES ━━</b>
Use templates to start fast, or build your own. Create a rule by choosing source folders, file extensions, and a destination. Each rule can move, copy or delete files, and you control what happens when a filename collision occurs — skip, overwrite, or rename automatically. Rules can scan subfolders recursively and each one gets its own schedule.

Moved files keep their original date and time (copies too, with All files access), so they stay in the right order in your gallery and file manager instead of showing up as brand new.

<b>━━ 🎛️ ADVANCED FILTERS ━━</b>
Not every file in a folder should match. Narrow things down with:
• Filename patterns (wildcards or RegEx)
• Minimum and maximum file size
• Minimum and maximum file age
• Exclude patterns (wildcards or RegEx)
• Media orientation (portrait or landscape)

All optional, all collapsed by default so simple rules stay simple.

<b>━━ 👁️ PREVIEW BEFORE YOU RUN ━━</b>
Not sure a rule will pick up the right files? <b>Preview</b> it first. FilePipe shows exactly which files would be moved — without touching anything on disk.

<b>━━ ⏰ FLEXIBLE SCHEDULES ━━</b>
Run rules on demand, or schedule them to run:
• Every few hours
• Daily at a specific time
• Weekly on a specific day and time

<b>━━ 📜 HISTORY ━━</b>
Every run is logged with a full per-file breakdown — moved, skipped, or failed. You can:
• Filter by outcome (including runs that matched nothing)
• Sort by date or rule name
• Switch between date view, rule view, or status view
• Tap a moved file to open it directly
• Undo a run to restore files when possible

<b>━━ ⚡ APP SHORTCUTS ━━</b>
Long-press the app icon to run any of your top four enabled rules immediately, without opening the app.

<b>━━ 🔔 NOTIFICATIONS ━━</b>
Scheduled runs post a summary notification showing the files that were moved. Tap <b>Undo</b> directly from the notification to reverse the last batch.

<b>━━ 💾 BACKUP AND RESTORE ━━</b>
Export your rules, run history, and settings to a JSON file and restore them at any time. Auto-export on rule change and scheduled exports are available in Settings.

<b>━━ 🎨 LOOK AND FEEL ━━</b>
• Light, dark, black (OLED), or system-default theme
• Material You (wallpaper colors on Android 12+)
• 8 fixed accent presets and option to set your own color
• 9 palette algorithms: Tonal Spot, Vibrant, Expressive, Rainbow, Monochrome, and more
• Optional gradient background
• Optional progressive blur behind the nav bar (Android 12+)
• Use your own custom font
• UI scale from 75% to 125% to make text, icons, and spacing smaller or larger

<b>━━ 🛡️ PRIVACY ━━</b>
Works entirely on-device. No accounts, no cloud sync, no data collection. You control how folders are accessed - either one at a time or grant once & access everything.
